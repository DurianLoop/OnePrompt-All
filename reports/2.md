## 总体结论

**当前没有已经达到 CVPR/ICCV/NeurIPS/MICCAI 主会方法论文标准的完整强贡献。但存在两个有价值、可继续发展的贡献胚胎：**

1. **多参考视觉提示中的参考敏感性基准与失败边界 (Reference-Instability Benchmark)**。在 MoNuSAC 40-query 留出集上，参考替换造成的 Dice 波动、尾部风险和多参考共识收益被系统量化；这是当前最可靠的正向资产。
2. **Prediction Consistency 作为无需学习的查询级风险信号**。以多参考预测分歧进行 query-level abstention，主 pipeline (DINOv2-L + SAM-B) 上 AURC=0.0158，CFR@80 降低 88.6%。

它们距离顶会主会仍共同缺少：未暴露确认队列、跨数据集/跨架构稳健性、与强外部基线的同条件比较、清晰的独立测试协议。

当前最诚实的投稿定位是 **workshop / benchmark / failure-boundary paper**。

## 一、GlaS 自动提示线：Phase 2, 3, 4

### Phase 2：候选点质量与 SAM 门控

**目标**：把参考图像/掩码经匹配转换为稀疏正负点，再用 SAM 分割 GlaS 腺体；核心门控是候选精度、目标组件覆盖及最终分割是否优于严格对照。

**实现**：
- 初版最多 5 个正点；重设计后扩大至 20 个正点
- 使用 30 个验证 query、90 个参考 episode
- 显式检查坐标和随机对照
- 使用 DINOv2 特征匹配 + SAM-B/SAM-L 稀疏提示

**关键结果**：

| 指标 | 初版 | 重设计 v1 |
|---|---|---|
| 平均点精度 | 0.9711 | 0.9717 |
| 随机点精度 | 0.5489 | 0.5378 |
| 组件覆盖 | 0.4188 (失败) | 0.6302 (通过) |

- Gate D 在两种 segmenter 上失败：SAM-B 的 P3 margin 为 -0.1579、win rate 0.4333、灾难失败率 0.6667；SAM-L 的 margin 为 -0.0969、win rate 0.4667、灾难失败率 0.4000

**结论**：`STOP_GLAS_SEGMENTER_FAILURE_CONFIRMED`。候选点精度高不等于可发表的方法有效性。可保留为重要控制实验：候选点局部命中不等于可分割性。

**发表价值**：F（不应作为方法主线，可作为后续提示性基准控制）

### Phase 3：自动区域/框提示

**目标**：规避稀疏点瓶颈，比较直接匹配掩码、自动并集框、最大组件框和 Top-3 组件框。

**实现**：先以区域 proposal 指标筛选，不运行 SAM。

**关键结果**：

| 路线 | 绝对指标 | 相对提升 | Win rate | 结论 |
|---|---|---|---|---|
| R00 直接匹配掩码 | 0.1788 | -0.4163 | 0.0667 | 失败 |
| R03 自动并集框 | 0.7448 | +0.0260 | 0.2000 | 失败 |
| R04 最大组件框 | 0.0194 | +0.0022 | 0.1000 | 失败 |
| R05 Top-3 框 | 0.2717 | +0.0166 | 0.1667 | 失败 |

**Phase 4 审计纠偏**：R03 看似很高的绝对 IoU 与大小/面积先验相容，大框高 IoU 很大程度可由面积先验解释。

**结论**：`STOP_GLAS_REGION_PROPOSAL_FAILURE`。已停止。价值在于证明"大框 IoU"必须以面积匹配随机控制解释。

**发表价值**：B（为 promptability benchmark 提供问题定义）

## 二、参考稳定性与多参考提示：Phase R, S, T

### Phase R：可行性预注册与第一轮否定

**目标**：分离 reference choice 对 frozen DINOv2 + SAM 提示管线的影响，并测试确定性共识是否降低不稳定性。

**实现**：
- MoNuSAC 数据集，patient-disjoint 参考采样
- DINOv2-L + SAM-B 两阶段管线
- 确定性共识：mean、median、trimmed mean 等

**关键结果**：
- Gate R1 确认参考不稳定性：88.75% queries 的 best-worst gap ≥ 0.05，mean reference std ≈ 0.0737
- Gate R2 显示共识没有满足方差降低的预注册条件
- Mean consensus 将 Dice 从约 0.4297 提高至 0.4756，并降低 catastrophic failure

**结论**：`PHASER_REFERENCE_STABILITY_NOT_FEASIBLE_DETERMINISTIC`。研究问题成立，初始方法不成立。该阶段另发现一个历史度量错误，Phase S 已修正。

**发表价值**：B（现象有效，方法失败）

### Phase S：多轨研究计划

**总目标**：在严格控制数据泄漏、验证集过拟合和事后调参的前提下，对多个潜在方向进行系统探索。

**四条注册路线**：
- Track A：Metric Correction and Stability Benchmark
- Track B：Learned Reference Reliability and Robust Aggregation
- Track C：Set-Conditioned Robust Prompting
- Track D：Direct Reference-Conditioned Segmentation

#### Track A：参考不稳定性 Benchmark

**实现**：使用 41 个验证 query、三种提示配置 (P20-N1, P30-N0, P50-N0) 和 k=1/3/6 参考集合，重算正确的 within-query 方差分解、best-worst gap、CVaR 和测试时安全特征。

**关键结果**：

| 主配置/现象 | P20-N1 | P30-N0 | P50-N0 |
|---|---|---|---|
| 参考方差占总方差 V_ref_frac | 0.3312 | 0.2456 | 0.1376 |
| best-worst gap >= 0.05 的 query 比例 | 90.2% | 82.9% | 80.5% |
| k=1 平均 within-query ref std | 0.1006 | 0.0893 | 0.0686 |

- Gate A 7/7 通过：尾部风险 CVaR_0.1=0.0738 < mean Dice=0.4756，测试时安全特征预测的 Spearman 为 0.8832

**结论**：`BENCHMARK_VALID`。但这是重复暴露的验证数据，为 B 级证据。

**发表价值**：B（可作基准/失败边界论文骨架）

#### Track B：学习可靠性加权

**实现**：预测参考 utility 的 Spearman 为 0.478，但加权共识对 uniform 的 mean Dice 为 -0.0024。

**关键结果**：
- ref std 仅下降 2.83%
- CVaR 反而略变差
- CFR 无改善
- 预注册核心条件失败

**结论**：`NO_GAIN`。不能作为方法贡献。

**发表价值**：F

#### Track C：集合条件鲁棒提示

**实现**：最佳 Dice 增益 +0.0047 < +0.005 门槛，CVaR -0.0031。

**结论**：`NO_GAIN`。未形成方法增益。

**发表价值**：F

#### Track D：直接参考条件分割

**实现**：计划的 feature concat/cross-attention/reference-token 等方法均未实现，因为原始 matching map Dice < 0.3，而 SAM point refinement 提升到约 0.48。

**结论**：`NOT_STARTED`。直接替换不满足启动因果条件。

**发表价值**：F

### Phase T：最强的留出与跨数据集实证

**目标**：在新的 MoNuSAC 40-query 留出集上进行端到端验证，并在 MoNuSeg 和 IDRID 上进行外部检查。

**实现**：
- DINOv2-L + SAM-B pipeline
- 40 个 holdout query、10 个 reference-resampling seed
- 三种提示配置 (P20-N1, P30-N0, P50-N0)
- k=1/3/6 参考集合
- 病人级 reference/query 互斥检查：0/2400 违规
- M1：动态参考预算策略
- M2：双模型选择性预测 (separate instability + catastrophic models)

**MoNuSAC holdout 关键结果 (10/10 预注册门控通过)**：

| 指标 | 结果 |
|---|---|
| 有 best-worst gap >= 0.05 的 query | 92.5% |
| k=1 mean within-query ref std | 0.0742 |
| V_ref_frac, k=1 | 0.1264–0.2627 |
| 平均单参考 Dice | 0.4792 |
| k=6 共识 Dice | 0.5058 |
| 共识增益 | +0.0266, bootstrap 95% CI lower = +0.0140 |
| 单参考 / k=6 CFR | 0.0633 / 0.0575 |
| 单参考 / k=6 prediction agreement | 0.6490 / 0.7190 |
| 最佳 disagreement-feature Spearman | 0.7241 |

**跨数据集**：

| 数据集 | N | 共识增益 | 结论 |
|---|---|---|---|
| MoNuSeg | 30 | +0.0149, CI lower +0.0069 | strong support |
| IDRID | 30 | -0.0118, CI lower -0.0318 | fail; 基线 Dice ≈ 0.10, CFR ≈ 0.90 |

**M2 选择性预测**：

| 指标 | Validation | Holdout |
|---|---|---|
| Instability AUROC | 0.9443 | 0.9283 |
| Catastrophic AUPRC | 0.4338 | 0.5277 |
| CFR reduction at 80% | 39.2% | 79.2% |
| ECE | 0.0425 | 0.027 |

- M2 跨数据集转移：ranking transfers (AUROC 0.87-0.99)，但 calibration 不转移到 IDRID (ECE 0.48)

**结论**：`PHASET_BENCHMARK_NEEDS_MORE_EVIDENCE`。10/12 门控通过。核心发现可靠，但跨数据集证据不足（仅 1/2 支持）。

**发表价值**：A/B（现有最强实证资产）

## 三、Phase U/V/W 与 V4 论文：历史资产与必须撤回的内容

### V4 论文概述

**标题**：Reference Reliability Estimation for Visual Prompting Pipelines

**核心主张**：
- 提出 Reference Reliability Estimation (RRE) 问题
- 反相关机制：instability 与 catastrophic failure 之间存在结构性反相关 (Pearson r=-0.49)
- RAMP：Reference-Adaptive Multi-Prompt Fusion，双模型选择性预测器
- RRN：Reference Reliability Network，轻量学习可靠性估计器 (AUROC=0.612)
- 外部比较：Top-K 0.446 优于 GF-SAM 0.388、MAUP 0.279 等

### VV4 审计结果

**最终状态**：`VV4_PARTIALLY_RECONSTRUCTABLE`

**Claim 统计**：92 条 Claim 提取
- A (VERIFIED): 14
- B (VERIFIED_WITH_QUALIFICATION): 17
- C (REPRODUCIBLE_BUT_NOT_INDEPENDENT): 4
- D (PARTIALLY_SUPPORTED): 48
- E (CONTRADICTED_BY_LATER_AUDIT): 8
- I (REQUIRES_NEW_EXPERIMENT): 1

**关键数字复现**：12/15 MATCH, 3 CANNOT_REPRODUCE (CycleSAM/H-SAM/SAM-Med2D)

### 已被证伪或降级的内容

1. **RAMP 不能作为主动方法**。原实现用 `np.random.normal(mean_dice, std_dice, ...)` 模拟逐参考 Dice；自适应 prompt config/reference budget 并未触发新的 matcher/SAM 推理。Phase W 确认 Full RAMP 零增量价值。
2. **反相关不是普适结构定律**。仅 SAM-B pipeline 经 Holm 校正显著；SAM-L、SAM2-T、SAM2-S 不支持。Phase AB 已从主文移除。
3. **RRN 只能放附录**。初始 AUROC ≈ 0.612，但 grouped CV 平均约 0.573，测试 query 过少。
4. **外部比较不完整**。GF-SAM/MAUP 可追溯但 backbone 不同；CycleSAM/H-SAM/SAM-Med2D 无可复现预测或 checkpoint。
5. **自然图像证据只有 fold-0**。不足以形成跨域结论。

**结论**：V4 不是伪造空文档，但不是可直接修辞修复的论文。只能作为新 benchmark/failure-boundary 工作的素材库。

**发表价值**：D/F（只能保留问题与部分历史现象）

## 四、Prediction Consistency：Phase AA/AB

### Phase AA：简化选择性预测

**目标**：将研究从复杂的多组件 RAMP 框架收缩为简化的选择性预测论文。

**方法**：`R_PC(q) = 1 - mean pairwise IoU` of segmentations from m=6 references。Coverage-based abstention with CFR and AURC as primary metrics。

**关键结果**：
- AA0：Phase V/W 矛盾审计 — Null model 冲突解决，SAM-L 显著性统一，anti-correlation 从主文移除
- AA1：41 验证 query = Validation Cohort，NOT holdout
- AA2：B4 Prediction Consistency：75% CFR@80 reduction on L+SAM-B
- AA4：5/5 pipelines 显示 directional support
- AA5：1/3 datasets 显示 directional support
- AA6：SAM-Med2D 从主表移除
- AA7：Anti-correlation 从主文移除

**结论**：`PHASEAA_PAPER_NEAR_READY` (12/14 gates)。核心贡献：RRE 问题定义 + Prediction Consistency 风险评分 + 多 pipeline 评估。

**发表价值**：B/C

## 五、Action-Space / Policy 线：Phase X 与 Y

### Phase X：候选空间和搜索神谕审计

**问题**：过去的策略学习失败，是策略没学好，还是可选 prompt action bank 本来就太弱？

**实现**：
- 扩展正点数 K+、负点数 K-、分组、调用预算
- 比较固定动作库、有限 bank oracle 与逐 episode search oracle
- GlaS 数据集

**关键结果**：

| 门控 | 关键结果 | 含义 |
|---|---|---|
| X1 | 旧 12-action bank 最佳 Dice 0.3712 | 历史基线低 |
| X2 | K+=100 时 component coverage 仍 0.433 < 0.5 | 候选生成器不足 |
| X3 | K=5->100 的 Dice +0.097, component recall +0.108 | 密集 prompt 有真实潜力 |
| X4 | 扩大 bank 最佳固定 Dice 0.5411 vs 0.3713 | 旧 bank 不充分 |
| X5 | search oracle 0.7256 vs bank oracle 0.6119, 差 0.1137 | 动作选择空间仍有可利用信号 |

**结论**：`REOPEN_POLICY_LEARNING`。这是很有价值的反事实诊断——以前的 policy 失败不能证明 adaptive prompting 不可能。但 oracle 使用标签选择动作，尚未提供可部署 policy。

**发表价值**：B/C（有意思的诊断贡献，缺真正策略）

### Phase Y：新查询策略可行性

**目标**：在 fresh-query 上把 Phase X 的 search-oracle 空间转化为策略。

**实现**：使用 fresh split train=80/validation=41/holdout=40。

**关键结果**：
- Y1 仅 2/6 通过，Y2 仅 1/5 通过
- 神谕差距小 (stable cross-reference oracle gap ≈ 0.0061)
- Search Oracle 对 reference 明显过拟合
- Holdout 未运行

**结论**：`PHASEY_SEARCH_ORACLE_DIAGNOSTIC_ONLY`。当前 policy-learning 路线关闭。

**发表价值**：F（策略学习路线关闭）

## 六、Phase 4+ DDR：参考可提示性 Benchmark 的早期探索

**动机**：Phase 2/3 的 GlaS 失败表明，应先问"reference-driven matching 是否能生成可被 prompt interface 使用的证据"，而不是直接优化路由或分割。

**实现**：
- 冻结 DDR train/valid manifest：train 383 images、964 positive image-intent queries；valid 149 images、401 queries
- 为每 query 构造三条 reference episode
- 先运行 DINOv2-L 候选匹配 smoke 与 16 个分层 image-intent 单元的诊断

**关键结果**：
- 单 episode valid MA 的 point precision/component coverage 均为 0
- 分层 16 单元的 mean point precision 0.0125，zero-precision fraction 0.9375
- 16/16 小而稀疏，15/16 无 candidate hit、无 component coverage、且不能胜过随机

**结论**：`ROUTE_B_DDR_FAILURE_TAXONOMY`。不是正面 method result，而是强烈的 promptability failure-taxonomy 信号。

**发表价值**：C（好问题，但还没有正面 benchmark 证据）

## 八、顶会强贡献可行性评估

### 候选 A：Reference-Instability Benchmark（最强）

**可讲的贡献**：
- 多参考 visual prompting 中，reference choice 是一个独立、可量化的误差来源
- MoNuSAC 留出集上 k=6 简单共识带来平均 Dice (+0.0266)、尾部风险和 prediction consistency 改善
- MoNuSeg 正向复现、IDRID 失败给出 promptability 边界
- 10/10 预注册门控通过

**为什么还不够**：
- 仅一个强留出域
- 外部域 1 胜 1 败
- 没有现代多模型矩阵、自然图像验证和顶级 baseline
- 更适合 MICCAI/CVPR workshop 或 benchmark track

**升级门槛**：新鲜第三医疗队列或自然图像 4-fold；至少两类 modern matcher/segmenter；公开 per-query artifact

---

### 候选 B：Prediction Consistency Selective Abstention（有方法味道）

**可讲的贡献**：
- 不训练的新风险信号：R_PC(q) = 1 - mean pairwise IoU
- 主 pipeline 上 AURC=0.0158, CFR@80 降低 88.6%
- 5/5 pipelines 方向性支持

**为什么还不够**：
- 同一开发生态反复暴露
- SAM2-S 无收益 (CFR reduction -1.6%)
- 外部数据只给边界
- 没有 fresh confirmation
- 不能把 88.6% CFR reduction 写成可泛化方法效果

**升级门槛**：新 cohort N>=75 的预注册确认；与 MC-dropout、ensemble、SAM confidence 等基线同条件比较

---

### 候选 C：Action-Space Inadequacy / Search-Oracle Diagnostic（有洞见但不是方法）

**可讲的贡献**：
- 小离散 prompt bank 会系统性低估 promptable segmentation 上限
- K+ scaling 与 search oracle 揭示动态 action space 的价值

**为什么还不够**：search oracle 不可部署，Phase Y 没能学出策略，候选覆盖仍不足。适合诊断/benchmark，不适合作为"新策略方法"。

---

### 候选 D：DDR Promptability Benchmark（未来资产）

**可讲的贡献**：统一度量 reference matching、target size/sparsity、candidate hit、component coverage 和 SAM prompt-interface control

**为什么还不够**：目前只有一个 representation 的极小开发诊断，且自动 candidate 结果几乎全失败

## 九、最终发表判定

| 目标 | 当前判定 |
|---|---|
| 顶会主会方法论文 (CVPR/ICCV/NeurIPS) | **否**：没有经过 fresh cohort 验证的、真实执行且跨域稳健的方法增益 |
| 顶会 workshop / benchmark track | **有条件可行**：以 Reference-Instability Benchmark + failure boundary 为核心，严守范围 |
| 高质量负结果/诊断论文 | **可行**：Action-space inadequacy 与 promptability failure taxonomy |
| 当前 V4 原稿投稿 | **不可行**：核心 RAMP 实现、反相关普适性、外部比较均不满足 |

## 十、推荐的研究决策

1. **不要合并所有阶段写一篇"万能 visual prompting 方法论文"**。GlaS、RAMP、RRN、反相关、policy learning 的失败边界不同，硬拼会造成错误归因。
2. **主线应选择 A 或 B，而非同时宣称**。最稳妥的是 Reference-Instability Benchmark + failure boundary；若获得 fresh cohort，再把 Prediction Consistency 升为其中一个受限的风险排序方法。
3. **DDR 作为独立第二项目**。先完成自动、GT-point、GT-box、full-image-box 四类控制，判断是 matcher、prompt interface 还是任务本身的限制。
4. **把负结果作为门控资产保存**。GlaS 自动点/区域、RAMP、Track B/C、Phase Y 都应被列为"已排除路径"，防止重复投入和论文中的选择性汇报。
5. **顶会目标的最短路径不是再加图表**。是在新的未暴露数据上用冻结协议完成一条简单、真实执行、可独立复跑的主要结论。
