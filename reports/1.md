# AdaPromptSet 全阶段研究汇总与发表价值审计

更新时间：2026-07-28

审计范围：`D:\SAM\adapromptset` 的 Git 分支、`reports/`、`docs/`、论文目录与 `VV4` 证据包。本文件以当前可访问的产物为准；“复现”若只是从 CSV/JSON 重新读数，会明确标为**产物回放**，不会等同于独立重跑。

## 总结结论

**当前没有已经达到 CVPR/ICCV/NeurIPS/MICCAI 主会方法论文标准的完整强贡献。**

现有实验确实沉淀了两个有价值、可继续发展的贡献胚胎：

1. **多参考视觉提示中的参考敏感性基准与失败边界。** 在 MoNuSAC 的 40-query 留出集上，参考替换造成的 Dice 波动、尾部风险和多参考共识收益被系统量化；这是当前最可靠的正向资产。
2. **自动提示中“候选/动作空间不足，而不是策略本身”的可证伪诊断框架。** GlaS 的 Phase X 表明更密集提示和搜索神谕可以显著提高上限，但已有小动作库不能代表真实可达上限；这是很好的诊断性研究起点，而非已完成的方法贡献。

它们距离顶会主会仍共同缺少：未暴露确认队列、跨数据集/跨架构稳健性、与强外部基线的同条件比较、清晰的独立测试协议，以及一个真实执行而非事后选择的改进方法。当前最诚实的投稿定位是**workshop / benchmark / failure-boundary paper**，而非宣称 SOTA 的主会方法论文。

## 1. GlaS 自动提示线：Phase 2、Phase 3 与 Phase 4

### Phase 2：候选点质量与 SAM 门控

**目标。** 把参考图像/掩码经匹配转换为稀疏正负点，再用 SAM 分割 GlaS 腺体；核心门控是候选精度、目标组件覆盖及最终分割是否优于严格对照。

**实现。** 初版最多 5 个正点；重设计后扩大至 20 个正点，使用 30 个验证 query、90 个参考 episode，显式检查坐标和随机对照。

**结果。**

| 指标 | 初版 | 重设计 v1 |
|---|---:|---:|
| 平均点精度 | 0.9711 | 0.9717 |
| 随机点精度 | 0.5489 | 0.5378 |
| 组件覆盖 | 0.4188，失败 | 0.6302，通过 |
| Gate C | fail | pass，进入 Gate D |

候选点在像素层面很准，却不保证覆盖足够多的目标组件。随后 Gate D 在两种 segmenter 上失败：SAM-B 的 P3 margin 为 `-0.1579`、win rate `0.4333`、灾难失败率 `0.6667`；SAM-L 的 margin 为 `-0.0969`、win rate `0.4667`、灾难失败率 `0.4000`。GlaS testA/testB 未访问。

**结论。** “候选精度高”不是可发表的方法有效性；该路线已排除为自动点提示的正面方法。可保留为一个重要控制：候选点局部命中不等于可分割性。

### Phase 3：自动区域/框提示

**目标与实现。** 规避稀疏点瓶颈，比较直接 matching mask（R00）、自动并集框（R03）、最大组件框（R04）和 Top-3 组件框（R05）；先以区域 proposal 指标筛选，不运行 SAM。

| 路线 | 绝对指标 | 相对提升 | Win rate | 结论 |
|---|---:|---:|---:|---|
| R00 直接匹配掩码 | 0.1788 | -0.4163 | 0.0667 | 失败 |
| R03 自动并集框 | 0.7448 | +0.0260 | 0.2000 | 失败 |
| R04 最大组件框 | 0.0194 | +0.0022 | 0.1000 | 失败 |
| R05 Top-3 框 | 0.2717 | +0.0166 | 0.1667 | 失败 |

**Phase 4 审计纠偏。** R03 看似很高的绝对 IoU 与大小/面积先验相容，大小匹配随机对照也高；R00 精确但严重漏检。因此自动框没有建立定位优势。

**结论。** 已停止；价值在于证明“大框 IoU”必须以面积匹配随机控制解释，不能作为区域提示方法的正面性能。

## 2. 参考稳定性与多参考提示：Phase R、S、T

### Phase R：可行性预注册与第一轮否定

**目标。** 分离 reference choice 对 frozen DINOv2 + SAM 提示管线的影响，并测试确定性共识是否降低不稳定性。

**结果。** Gate R1 确认参考不稳定性；Gate R2 显示共识没有满足方差降低的预注册条件，因此给出 `PHASER_REFERENCE_STABILITY_NOT_FEASIBLE_DETERMINISTIC`。该阶段另发现一个历史度量错误，Phase S 已修正，故 Phase R 的单独正面数值不能直接引用。

**价值。** 研究问题成立，初始方法不成立。这是健康的研究分叉而非可投稿方法结果。

### Phase S：多轨研究计划

**Track A，参考不稳定性 benchmark。** 使用 41 个验证 query、三种提示配置和 k=1/3/6 参考集合，重算正确的 within-query 方差分解、best-worst gap、CVaR 和测试时安全特征。

| 主配置/现象 | P20-N1 | P30-N0 | P50-N0 |
|---|---:|---:|---:|
| 参考方差占总方差 `V_ref_frac` | 0.3312 | 0.2456 | 0.1376 |
| best-worst gap >= 0.05 的 query 比例 | 90.2% | 82.9% | 80.5% |
| k=1 平均 within-query ref std | 0.1006 | 0.0893 | 0.0686 |

Gate A 7/7 通过：尾部风险 `CVaR_0.1=0.0738 < mean Dice=0.4756`，测试时安全特征预测的 Spearman 为 `0.8832`。但这是重复暴露的验证数据和 CPU 对历史产物的再分析，故为 B 而非新的确认性 A 级证据。

**Track B，学习可靠性加权。** 预测参考 utility 的 Spearman 为 `0.478`，但加权共识对 uniform 的 mean Dice 为 `-0.0024`，ref std 仅下降 `2.83%`，CVaR 反而略变差，CFR 无改善；预注册核心条件失败。

**Track C，集合条件鲁棒提示。** 最佳 Dice 增益 `+0.0047` 小于 `+0.005` 门槛，CVaR `-0.0031`，未形成方法增益。

**Track D，直接参考条件分割。** 计划的 feature concat/cross-attention/reference-token 等方法均未实现，因为原始 matching map Dice `<0.3`，而 SAM point refinement 提升到约 `0.48`；直接替换并不满足启动因果条件。

**Track S 总结。** 最终允许的只是“benchmark + failure boundary”：有效参考在 frozen pipeline 中会产生大量可测的变异；utility 可预测却没有转化为可部署的 Dice 增益。

### Phase T：最强的留出与跨数据集实证

**实现。** 对 MoNuSAC 40 个 holdout query、10 个 reference-resampling seed、三种提示配置和 k=1/3/6 做端到端 DINOv2-L + SAM-B 运行；病人级 reference/query 互斥检查为 0/2400 违规。该阶段是当前最接近 A 级的证据。

**MoNuSAC holdout。** 10/10 预注册门控通过：

| 指标 | 结果 |
|---|---:|
| 有 best-worst gap >= 0.05 的 query | 92.5% |
| k=1 mean within-query ref std | 0.0742 |
| `V_ref_frac`，k=1 | 0.1264–0.2627 |
| 平均单参考 Dice | 0.4792 |
| k=6 共识 Dice | 0.5058 |
| 共识增益 | +0.0266，bootstrap 95% CI lower = +0.0140 |
| 单参考 / k=6 CFR | 0.0633 / 0.0575 |
| 单参考 / k=6 prediction agreement | 0.6490 / 0.7190 |
| 最佳 disagreement-feature Spearman | 0.7241 |

这是一个**值得发表的基准现象**：多参考共识在严格留出集上改善平均 Dice、最差情况和预测一致性，同时参考不稳定性没有消失。

**跨数据集。**

| 数据集 | N | 共识增益 | 结论 |
|---|---:|---:|---|
| MoNuSeg | 30 | +0.0149，CI lower +0.0069 | strong support |
| IDRID | 30 | -0.0118，CI lower -0.0318 | fail；基线 Dice 约 0.10、CFR 约 0.90 |

这给出了一个有用的边界条件：当基础 promptability 很低时，reference consensus 不会挽救系统。它也意味着“跨医学数据集普适改善”的表述不成立。

## 3. Phase U/V/W 与 V4 论文：历史资产和必须撤回的内容

### 原论文的主张与可回放部分

V4 提出 RRE、反相关机制、RAMP、RRN 和外部比较。VV4 包含 PDF、LaTeX、代码和结果；活跃与归档 V4 PDF 的 SHA-256 一致。92 个声明中，审计分类为 A=14、B=17、C=4、D=48、E=8、I=1。60 项“复现”中 55 项是 Level-1 artifact replay，而非独立重跑。

可保留的是 RRE 问题、部分基准数值和参考变异现象；不能把“文件存在、读数一致”误写为方法已独立验证。

### 已被证伪或降级的内容

1. **RAMP 不能作为主动方法。** 原实现用 `np.random.normal(mean_dice, std_dice, ...)` 模拟逐参考 Dice，所谓自适应 prompt config/reference budget 并未触发新的 matcher/SAM 推理。原消融中多个变体 Dice 完全一致。RAMP 只能解释为事后、同队列风险排序，不能宣称主动自适应改善。
2. **反相关不是普适结构定律。** 后续 query-level 分析仅 SAM-B pipeline 经 Holm 校正显著；SAM-L、SAM2-T、SAM2-S 不支持，且 random-beta null 可复制 94% 的相关强度。理论必须改为待检验的管线特异经验假设。
3. **RRN 只能放附录。** 初始 AUROC 约 0.612 的小 split 可读回，但 grouped CV 平均约 0.573，且测试 query 过少。
4. **外部比较不完整。** GF-SAM/MAUP 的部分结果可追溯，但 backbone 不同；CycleSAM/H-SAM/SAM-Med2D 无可复现预测或 checkpoint；MC dropout/deep ensemble 是 proxy。
5. **自然图像证据只有 fold-0。** 不足以形成跨域结论。

**结论。** V4 不是伪造空文档，但不是可直接修辞修复的论文。它只能作为新的 benchmark/failure-boundary 工作的素材库，不能作为顶会方法论文。

## 4. Prediction Consistency：Phase AA/AB 的可用但尚未确认方向

**方法。** 对同一 query 的多个参考生成多个 SAM masks，使用 `R_PC(q)=1-mean pairwise IoU` 作为无需附加训练、GT-free 的查询级风险排序信号，并按 coverage 执行 abstention。

**主 pipeline 的开发结果，DINOv2-L + SAM-B。** AURC `0.0158`，而随机为 `0.1295`；80% coverage 时 CFR 从 `0.1536` 降到 `0.0156`，CFR reduction `88.6%`，Dice@80 `0.5007`。该信号在 5 个 pipeline 上方向性为正，但强弱高度异质：SAM-L `23.1%`、SAM2-T `9.1%`、SAM2-S `-1.6%` CFR reduction。

**范围。** MoNuSAC 开发集 N=80；MoNuSeg N=30 是失败率为零的边界；IDRID N=30 基础质量过低；Validation41 已被暴露而不是 holdout。Phase AB 明确因为没有 fresh cohort 而给出 `PHASEAB_NEEDS_FRESH_DATA`。

**评价。** 这是 V4 后唯一仍有“简单可用方法”形状的候选，但目前仅 B/C 级。顶会主会至少需要一个完全未暴露 cohort 上的预注册确认、真实不确定性基线和跨架构稳定收益；否则只能作为 workshop 风险选择性预测论文。

## 5. Action-space / policy 线：Phase X 与 Y

### Phase X：候选空间和搜索神谕审计

**问题。** 过去的策略学习失败，是策略没学好，还是可选 prompt action bank 本来就太弱？

**实现。** 扩展正点数 K+、负点数 K-、分组、调用预算；比较固定动作库、有限 bank oracle 与逐 episode search oracle。

| 门控 | 关键结果 | 含义 |
|---|---|---|
| X1 | 旧 12-action bank 最佳 Dice 0.3712 | 历史基线低 |
| X2 | K+=100 时 component coverage 仍 0.433 < 0.5 | 候选生成器不足 |
| X3 | K=5 -> 100 的 Dice +0.097，component recall +0.108 | 密集 prompt 有真实潜力 |
| X4 | 扩大 bank 最佳固定 Dice 0.5411 vs 0.3713 | 旧 bank 不充分 |
| X5 | search oracle 0.7256 vs bank oracle 0.6119，差 0.1137 | 动作选择空间仍有可利用信号 |

**结论。** 这是很有价值的反事实诊断：以前的 policy 失败不能证明 adaptive prompting 不可能。可是 oracle 使用标签来选择动作，尚未提供可部署 policy；因此不能写成方法提升。

### Phase Y：新查询策略可行性

**目标。** 在 fresh-query 上把 Phase X 的 search-oracle 空间转化为策略。

**结果。** Y1 仅 2/6 通过，Y2 仅 1/5 通过；神谕差距小、搜索神谕过拟合，holdout 未运行。最终 `PHASEY_SEARCH_ORACLE_DIAGNOSTIC_ONLY`。

**结论。** 当前 policy-learning 路线关闭。Phase X 可以成为“为何静态动作库会低估视觉提示上限”的分析论文的一部分，但要重启方法路线需新的 candidate generator/表征，而不能继续在相同策略表上调参。

## 6. Phase 4+ DDR：参考可提示性 benchmark 的早期探索

**动机。** Phase 2/3 的 GlaS 失败与 Phase 4 控制审计表明，应先问“reference-driven matching 是否能生成可被 prompt interface 使用的证据”，而不是直接优化路由或分割。

**实现。** 冻结 DDR train/valid manifest：train 383 images、964 positive image-intent queries；valid 149 images、401 queries；为每 query 构造三条 reference episode。formal test 锁定未读。先运行 DINOv2-L 候选匹配 smoke 与 16 个 train/valid 分层 image-intent 单元的诊断。

**结果。** 单 episode valid MA 的 point precision/component coverage 均为 0。分层 16 单元的 mean point precision `0.0125`，zero-precision fraction `0.9375`；16/16 小而稀疏，15/16 无 candidate hit、无 component coverage、且不能胜过随机。

**结论。** 这不是正面 method result，而是强烈的 promptability failure-taxonomy 信号。下一步必须先做 point/box/full-image 等 prompt-interface controls，并引入多数据集/多表征；不能把同一 DINOv2 candidate-only 失败重复包装成 benchmark 成功。

## 是否已有可投顶会的强 contribution？

### 候选 A：Reference-instability benchmark（最强）

**可讲的贡献。** 多参考 visual prompting 中，reference choice 是一个独立、可量化的误差来源；其严重程度在 MoNuSAC 留出集上成立，并且 k=6 简单共识带来平均 Dice、尾部风险和 prediction consistency 改善。MoNuSeg 正向复现、IDRID 失败进一步给出 promptability 边界。

**为什么还不够。** 仅一个强留出域；外部域 1 胜 1 败；没有现代多模型矩阵、自然图像验证和顶级 baseline。它更像 MICCAI/CVPR workshop 或 benchmark track 的一篇扎实论文，尚不足主会强贡献。

**升级门槛。** 新鲜第三医疗队列或自然图像 4-fold；冻结的 reference protocol；至少两类 modern matcher/segmenter；公开的 per-query artifact；独立 reviewer 能复跑的环境和数据 manifest。

### 候选 B：Prediction Consistency selective abstention（有方法味道）

**可讲的贡献。** 不训练的新风险信号，以多参考预测分歧进行 query-level abstention；主 pipeline 上风险曲线很强。

**为什么还不够。** 同一开发生态反复暴露；在 SAM2-S 无收益、外部数据只给边界；没有 fresh confirmation。不能把 88.6% CFR reduction 写成可泛化方法效果。

**升级门槛。** 新 cohort N>=75 的预注册确认；patient/query-grouped evaluation；与真正 MC-dropout、ensemble、SAM confidence 等基线同条件比较；明确 post-hoc 成本和覆盖率选择协议。

### 候选 C：Action-space inadequacy / search-oracle diagnostic（有洞见但不是方法）

**可讲的贡献。** 小离散 prompt bank 会系统性低估 promptable segmentation 上限；K+ scaling 与 search oracle 揭示动态 action space 的价值。

**为什么还不够。** search oracle 不可部署，Phase Y 没能学出策略，候选覆盖仍不足。该工作适合诊断/benchmark，不适合作为“新策略方法”。

### 候选 D：DDR promptability benchmark（未来资产）

**可讲的贡献。** 统一度量 reference matching、target size/sparsity、candidate hit、component coverage 和 SAM prompt-interface control，定位“匹配失败还是接口失败”。

**为什么还不够。** 目前只有一个 representation 的极小开发诊断，且自动 candidate 结果几乎全失败；尚无控制实验和多域统计。

## 推荐的研究决策

1. **不要合并所有阶段写一篇“万能 visual prompting 方法论文”。** GlaS、RAMP、RRN、反相关、policy learning 的失败边界不同，硬拼会造成错误归因。
2. **主线应选择 A 或 B，而非同时宣称。** 最稳妥的是 Reference-instability benchmark + failure boundary；若获得 fresh cohort，再把 Prediction Consistency 升为其中一个受限的风险排序方法。
3. **DDR 作为独立第二项目。** 先完成自动、GT-point、GT-box、full-image-box 四类控制，判断是 matcher、prompt interface 还是任务本身的限制；之后才决定做 benchmark 或新 matcher。
4. **把负结果作为门控资产保存。** GlaS 自动点/区域、RAMP、Track B/C、Phase Y 都应被列为“已排除路径”，防止重复投入和论文中的选择性汇报。
5. **顶会目标的最短路径不是再加图表。** 是在新的未暴露数据上用冻结协议完成一条简单、真实执行、可独立复跑的主要结论。
