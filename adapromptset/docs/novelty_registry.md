# Novelty Registry

Date: 2026-07-19

## Works Requiring Explicit Boundary

- GF-SAM / graph-based few-shot SAM.
- SynPo / high-quality negative prompts.
- AlignSAM / RL prompt optimization.
- Point Prompt Defender / adversarial prompt agents.
- Reference-guided SAM and automatic prompt generation.
- Prompt routing and selective prediction.
- Abstention and calibration.
- Few-shot segmentation and medical foundation segmentation.
- Matching-based dense segmentation.

## Phase 4+ Novelty Questions

1. Is the chosen problem already explicitly solved?
2. Are the inputs, outputs, action space, and training signal different from closest work?
3. Is the contribution more than combining existing modules?
4. Can the core contribution be expressed in one falsifiable sentence?
5. Does the contribution remain meaningful outside a single dataset?
6. Does it remain meaningful if the original adaptive-policy story is removed?
7. Is there a risk of "more experiments only" pseudo-novelty?

## Current Boundary

The project cannot claim first learned prompting, universal transfer, model-agnostic behavior, plug-and-play deployment, or automatic region prompting success from the existing Phase 1-3 evidence.
