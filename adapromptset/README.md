# AdaPromptSet

AdaPromptSet is a gated, reproducible MVP package for cost-aware prompt-set selection in reference-guided dense medical segmentation.

Current execution boundary:

- Development data: MoNuSAC.
- Sanity/historical data: MoNuSeg.
- First extension data: GlaS.
- Frozen MVP matcher/segmenter scope: DINOv2-L + SAM-B.
- DDR, IDRID, CPM-17, SAM-L/H, SAM2, and SAM3 are excluded from first-round tuning.
