\section{Related Work}
GF-SAM, SynPo, AlignSAM, and Point Prompt Defender define the nearest boundaries. This draft does not claim to be first to learn prompts or the first learned prompting method, and does not claim broad transfer.

GF-SAM-style work motivates graph or region-level prompt construction from reference evidence, but the current AdaPromptSet artifact does not implement or rank a complete GF-SAM graph baseline as a finished comparable method. SynPo-style prompting motivates explicit negative evidence, but the present bank treats negative candidates as one family among several complete prompt-set actions. AlignSAM and Point Prompt Defender motivate sequential or adversarial prompt policies; those paths are intentionally non-mainline here because the registered experiment is one-shot, offline, and budgeted at the complete-action level.

The related-work boundary matters for interpreting the pivot. If AdaPromptSet had claimed novelty from any single primitive, then a failed Gate F would be hard to read. Instead, the registered object is the decision problem over a frozen bank. The present result says that, for this bank and pilot, the decision problem did not expose enough useful action heterogeneity. It does not erase the value of prior prompt engineering work, and it does not convert background reference evidence into explicit SAM negative points. The paper therefore keeps the table as a boundary registry rather than a superiority table.
