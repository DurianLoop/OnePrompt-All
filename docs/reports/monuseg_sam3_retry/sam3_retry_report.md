## 结论

- SAM3 point prompt 可以运行，也支持累计点。
- SAM3 text 对 `white girl`、`execute` 的失败已在 smoke 中复现。
- 但 SAM3 在 MonuSeg dense positive point 上明显弱于 SAM baseline。
- 因此下一步要把 SAM3 作为单独问题研究，不能把 SAM baseline 的 dense point 结论直接迁移。
