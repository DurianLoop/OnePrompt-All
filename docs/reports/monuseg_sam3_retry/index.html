MonuSeg Dense Point Prompt：SAM3 重测报告

这次重测专门修正上一版问题：上一版主实验用的是 SAM ViT-B，不是 SAM3。本版使用本地 assets/checkpoints/sam3_modelscope/sam3.pt，并把 K/lambda 网格补密。

模型说明：上一版 340 candidates 是 SAM baseline；本版 1460 candidates 是 SAM3。两者不能混写成同一个结论。

核心发现：SAM3 在 MonuSeg dense positive point 上明显弱于 SAM baseline。SAM3 候选池 oracle Dice 只有 0.1287，而 SAM baseline 是 0.4464。这说明“dense matched points 对 SAM 有效”不能直接推出“对 SAM3 也有效”。

7. 现在应该怎么汇报

第一句话要先纠正：上一轮主实验是 SAM，不是 SAM3。重测后，SAM3 确实支持累计点，但在 MonuSeg all-nuclei dense prompt 上效果弱，这本身是一个重要结果。

后续不应直接把 SAM3 当成 SAM 的替代模型。更合理的路线是：SAM baseline 用来证明 matcher dense point 的候选池价值；SAM3 单独研究 prompt 行为，尤其是为什么多点不能稳定合成全图细胞核 mask，以及是否需要 negative points、box/mask guidance 或不同的 instance-to-all aggregation。
