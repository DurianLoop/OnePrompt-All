T1. Foreground-Background Contrastive Matching

reference 图不是只提供一个目标框，而是有人工 mask。因此我们同时利用 mask 内的 foreground prototype 和 mask 外的 background prototype：

score(x)=z(sim(query_x, foreground_proto))-lambda*z(sim(query_x, background_proto))

这一步回应你的想法：我们要找的是“最像细胞核前景，同时最不像参考背景”的点，而不是只按前景相似度排序。

T3. 点数预算：K 取多少

固定 foreground-only、top-k、无聚类，只看一次性送入 SAM 的点数。结果说明 K=1 几乎不够，K=10 后 recall 大幅提升，K=20 达到本轮 Dice 峰值；继续加到 50/100 会提高 recall，但预测面积和 merge 风险也上升。

下一步研究路线

第一优先级：沿着 MonuSeg 单域，把 K 和 lambda 从人工网格搜索改成验证集可学习策略。

第二优先级：加入 negative/background points，但只在预测面积过大或 merge error 高的 case 触发，避免重新引入太多变量。

第三优先级：把 local maxima 和 top-k 结合成一个可学习 point policy，输入 score map 的峰值数量、熵、面积估计和 background score，输出 K 与点布局。

第四优先级：在 MonuSeg 稳定后，再迁移到 IDRID 或其他 domain；不要现在就把跨域作为主线。
